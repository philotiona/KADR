# Установка KADR

## Форматы поставки
| | AAB (Android App Bundle) | APK |
|---|---|---|
| Файл | `KADR-X.Y.Z.aab` | `KADR-X.Y.Z.apk` |
| Для чего | Загрузка в Google Play / Huawei AppGallery | Прямая установка, GitHub Releases, RuStore |
| Можно установить на телефон | Нет, только через магазин или `bundletool` | Да |
| Подпись | JAR-подпись upload-ключом; пользователю магазин выдаёт APK, подписанные app signing key | APK Signature Scheme v2 ключом `kadr-upload` |
| Размер KADR 1.0.0 | 106 092 Б (внутри `proguard.map` 396 КБ для автодеобфускации) | 70 824 Б |
| Оптимизация | Магазин генерирует split APK под ABI, плотность экрана и язык | Один универсальный файл для всех устройств |

## Установка APK из GitHub Releases (неизвестные источники)
1. На телефоне откройте страницу релиза <https://github.com/philotiona/KADR/releases/latest> и скачайте `KADR-X.Y.Z.apk`.
2. Откройте файл из уведомления о загрузке или из приложения «Файлы» → «Загрузки».
3. Android покажет предупреждение: установка из этого источника запрещена. Нажмите **Настройки**.
4. В разделе **Установка неизвестных приложений** включите **Разрешить из этого источника** для браузера или «Файлов».
   (Android 7.x: Настройки → Безопасность → **Неизвестные источники**.)
5. Вернитесь назад и нажмите **Установить**. Если Google Play Защита предложит проверку, нажмите **Проверить приложение**.
6. После установки отключите разрешение из шага 4.
7. Проверьте контрольную сумму, если нужно: `certutil -hashfile KADR-X.Y.Z.apk SHA256` сравните с `SHA256SUMS.txt` в релизе.

## Установка через ADB (разработчик)
```bash
adb install -r KADR-1.0.0.apk
```
`INSTALL_FAILED_UPDATE_INCOMPATIBLE` означает, что установлена сборка с другой подписью (например, debug). Удалите её: `adb uninstall com.example.kaspikids`.

## Требования
Android 7.0 (API 24) и новее, 5 МБ свободного места. Разрешения не требуются.
