# Работа с обращениями KADR (задание 15, часть А)

## Каналы
- GitHub Issues (шаблоны: Ошибка, Пожелание, Вопрос) — кнопка «Сообщить о проблеме» в приложении.
- Отзывы в магазине (Google Play / RuStore) — ответ в консоли.

## Приоритеты и SLA
| Приоритет | Метка | Критерий | Первый ответ | Решение |
|---|---|---|---|---|
| P0 | `P0-critical` | Сбой у многих, потеря брони/данных, безопасность | 2 ч | 24 ч (hotfix) |
| P1 | `P1-high` | Ключевая функция не работает, есть обходной путь | 1 рабочий день | Ближайший PATCH (≤ 7 дней) |
| P2 | `P2-medium` | Неудобство, пожелание с большим спросом | 3 рабочих дня | Плановый MINOR |
| P3 | `P3-low` | Косметика, вопрос | 5 рабочих дней | По возможности |

Отзывы в магазине: ответ ≤ 2 рабочих дня; негативные с описанием ошибки — переносятся в issue.

## Тестовые отзывы в магазине и ответы
Приложение опубликовано через GitHub Releases, где нет раздела отзывов, поэтому ответы подготовлены по правилам Google Play (≤ 350 символов, вежливо, без персональных данных, с конкретным действием).

| № | Тестовый отзыв | Оценка | Ответ разработчика |

| 1 | «После обновления приложение закрывается сразу после входа» | ★☆☆☆☆ | «Спасибо, что сообщили! Это ошибка версии 1.2.0, мы уже выпустили исправление 1.2.1. Обновите приложение в «Кабинет → Проверить обновления». Если проблема останется, напишите нам через «Сообщить о проблеме».» |
| 2 | «Удобный выбор мест, но хочется оплачивать прямо в приложении» | ★★★★☆ | «Рады, что выбор мест удобен! Онлайн-оплату мы записали в план развития (обращение #2). Сейчас оплата проходит в кассе — покажите код брони кассиру.» |
