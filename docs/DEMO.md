# Демонстрация проекта

1. Откройте проект в Android Studio или установите output/KADR.apk.
2. Войдите как admin / Admin123!. На главном экране видны приветствие, личный кабинет, регистрация пользователей и выход.
3. Зарегистрируйте нового пользователя через «Регистрация пользователей». Выберите роль «Пользователь» и пароль от 8 символов.
4. Выйдите и войдите новым аккаунтом. Регистрация пользователей скрыта. Измените имя в личном кабинете и проверьте приветствие.
5. Найдите фильм, выберите дату и сеанс, отметьте места. Примените FIRST (10%) или STUDENT (15%). Забронируйте.
6. Откройте билет в «Билеты». Сохраните PNG, экспортируйте ICS или поделитесь деталями. Отмена до сеанса освобождает места.
7. Войдите администратором: «Управление» → «Бронирования и касса». Найдите билет по коду, подтвердите фактически полученную оплату.
8. Для проверки входа создайте сеанс, начинающийся через 30 минут, в свободном зале. Забронируйте и оплатите его; «Проверить и погасить билет» доступно за час до начала. Повторный проход отклоняется.
9. Попробуйте создать пересекающиеся сеансы одного зала: приложение покажет ошибку. Сеанс с бронями нельзя редактировать; его можно отменить целиком.
10. Через Android Studio → App Inspection → Database Inspector покажите users, shows, bookings и booking_seats. Файл схемы — docs/schema.sql.

Oracle не требуется. БД каждого устройства отдельная. Оплата выполняется в кассе.

Отчёт использует титульный лист из предоставленного CLOUDLAB1. Проверьте название дисциплины и преподавателя перед сдачей; остальные данные перенесены из вашего образца.
