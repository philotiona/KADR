# База данных внутри KADR

Откройте приложение, войдите и нажмите «База» в нижней навигации. Раздел читает настоящий приватный файл приложения `kadr_cinema.db`; ER-схема формируется из метаданных SQLite, а не из заранее нарисованного изображения.

- **ER:** все таблицы, столбцы, PK/FK и связи 1 : 0..N. Масштаб двумя пальцами или кнопками, перемещение, поиск таблицы/столбца, переход из списка, нажатие таблицы для подробностей. Положение диаграммы сохраняется при переключении разделов.
- **Таблицы:** столбцы и типы, ключи, NULL/default, индексы, переход по внешнему ключу, просмотр и копирование CREATE TABLE.
- **Записи:** только администратору. Поиск по открытым значениям, сортировка ASC/DESC, страницы по 50 строк, горизонтальная прокрутка, подробности строки. CSV сохраняет текущую страницу с учётом поиска и сортировки. Пароли, соли и хеши токенов скрыты, включая CSV.
- **Проверки:** quick_check, число нарушений внешних ключей, состояние foreign_keys, версия и размер файла, список связей. Запускаются кнопкой «Проверить базу».
- **Экспорт SQL:** DDL таблиц и индексов без записей. Android предлагает выбрать место сохранения; широкие разрешения на хранилище не нужны.

Обычный пользователь может изучать схему, экспортировать SQL и запускать проверки. Счётчики записей ему скрыты. Для просмотра строк используйте действующий аккаунт администратора; исходный демонстрационный аккаунт — `admin` / `Admin123!`, если его пароль не меняли.

Просмотр не изменяет схему или записи. Создание/изменение фильмов, сеансов, бронирований и других данных остаётся в существующих экранах приложения. Облачная БД и Oracle для этого раздела не нужны.

## Проверка

Запустите эмулятор и выполните `tests/database.ps1` из PowerShell. Скрипт использует уже установленный Gradle офлайн, собирает APK в `output/database-build`, устанавливает их и запускает целевые инструментальные проверки. Тестовые данные создаются в отдельной БД; для UI временно создаются сессии существующих пользователей, затем удаляются, а прежняя сессия восстанавливается. Результат и изображения сохраняются в `build/database-explorer-tests.log` и `output/screenshots`.

Проверено 3 ноября 2026: 35 проверок прошли — метаданные, роли, защита запросов, скрытие секретов, поиск/сортировка/страницы, целостность, CSV, реальное сохранение SQL и навигация на Android. Схема приложения и версия БД не менялись.
